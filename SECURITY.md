# Politica di sicurezza

## Versioni supportate

| Versione | Supportata |
|---|---|
| 2.1.x | ✓ |
| 2.0.x | Solo bug critici |
| < 2.0 | ✗ |

## Segnalazione di vulnerabilità

**Non aprire Issue pubbliche per vulnerabilità di sicurezza.**

Per segnalare una vulnerabilità in modo responsabile:

1. Invia una e-mail a: `gianmarco.chirico@clebari.com`
2. Includi una descrizione dettagliata del problema, i passi per riprodurlo
   e, se disponibile, una Proof of Concept.
3. Riceverai una risposta entro **5 giorni lavorativi**.
4. La vulnerabilità verrà corretta e resa pubblica dopo un periodo di
   **coordinated disclosure** (tipicamente 90 giorni).

## Note

Questo strumento è un'applicazione desktop che opera esclusivamente su file
locali. Non espone endpoint di rete né gestisce autenticazioni. Le credenziali
MyPay (password ente) non vengono mai salvate dal software.
